❌ L'image n'apparaît pas
   → Vérifier que le ML Server est lancé
   → Ouvrir F12 et regarder la console
   → Vérifier la réponse API contient "image_base64"

❌ L'image est floue
   → NORMAL! C'est une image 64x64 agrandie
   → Le style "pixelated" est volontaire

❌ L'image ne correspond pas
   → Vérifier le format: [[dx, dy, pen], ...]
   → Regarder les logs du ML Server
   → Vérifier vector_to_image() dans ml_server.py

1. FRONTEND: Collecte points [dx, dy, pen]
             ↓
2. FRONTEND: Envoie POST /predict_cnn
             ↓
3. BACKEND:  Convertit en image 64x64
             ├─→ Deltas → Coordonnées absolues
             ├─→ Normalisation
             └─→ Dessin sur canvas PIL
             ↓
4. BACKEND:  Conversion image → base64
             ↓
5. BACKEND:  Inférence CNN sur l'image
             ↓
6. BACKEND:  Retour JSON:
             {
               "predicted_index": 5,
               "confidence": 87.43,
               "image_base64": "data:image/png;base64,..."
             }
             ↓
7. FRONTEND: Affiche prédiction + image!
